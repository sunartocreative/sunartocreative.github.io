Analisis Data Dengan Python - Dicoding

Overview

Analisis Data Dengan Python – Dicoding merupakan proyek analisis data pertama yang dikerjakan sebagai bagian dari proses pembelajaran pada kursus analisis data di Dicoding. Proyek ini bertujuan untuk menerapkan konsep dasar analisis data menggunakan Python dengan memanfaatkan Jupyter Notebook sebagai lingkungan pengembangan. Dalam prosesnya, digunakan beberapa library utama seperti NumPy dan Pandas untuk pengolahan dan manipulasi data, serta Matplotlib dan Seaborn untuk visualisasi data.

Selain itu, proyek ini menerapkan tahapan data wrangling yang meliputi proses gathering data, assessing data, dan cleaning data guna memastikan kualitas dan kesiapan data sebelum dianalisis. Setelah data diproses, dilakukan Exploratory Data Analysis (EDA) untuk menggali pola, tren, dan insight awal dari dataset yang digunakan. Melalui proyek ini, diperoleh pemahaman dasar mengenai alur kerja analisis data secara sistematis, mulai dari pengolahan data mentah hingga penyajian informasi dalam bentuk visual yang mudah dipahami.

Utility

Acer Aspire 5, Windows 11, mouse, Internet, Python, Jupyter Notebook, Pandas, Numpy, Matplotlib, Seaborn, chatGPT, Programming Thinking.
